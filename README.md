# Antigravity Sync Plugin (Cross-Platform)

Кроссплатформенный плагин резервного копирования и синхронизации для **macOS, Linux и Windows**.
Поддерживает синхронизацию конфигурации Antigravity и выбранных пользовательских проектов через **Git** и **Google Drive**.

---

## Что синхронизируется:
1. **Конфигурация Antigravity** (`~/.gemini/config/` / `%USERPROFILE%\.gemini\config\`):
   - Навыки (`skills/`)
   - Правила агентов (`rules/`)
   - MCP-серверы (`mcp_config.json`)
   - Установленные плагины (`plugins/`)
   - Параметры среды (`config.json`)
2. **Артефакты brain** (`~/.gemini/antigravity/brain/`)
3. **Отслеживаемые проекты** (любые выбранные вами репозитории и папки)

---

## Безопасность и защита данных (Zero-Leakage):
* **Автоматическое исключение секретов:** файлы `.env*`, приватные ключи (`id_rsa*`, `*.pem`, `*.key`), токены авторизации (`jetski-standalone-oauth-token`, `*.token`), SQLite WAL-файлы (`*.db-wal`, `*.db-shm`) и креденшелы никогда не попадут в репозиторий или облако.
* **Исключение тяжелых файлов:** папки `node_modules`, `.venv`, `.git`, `dist`, `build`, кэши и логи отфильтровываются автоматически.
* **Защита от Path Traversal:** системные каталоги (`/etc`, `/System`, `C:\Windows`, домашняя папка целиком) заблокированы для добавления.
* **Атомарная запись JSON:** защита конфигурационных файлов от повреждения при сбоях питания или аварийном завершении.
* **Кроссплатформенная адаптация путей:** при синхронизации проекта между разными ОС (например, с Windows на macOS) путь автоматически безопасно адаптируется в `~/Developer/<project_name>`.

---

## Запуск на разных платформах:
* **macOS / Linux:**
  `~/.gemini/config/plugins/antigravity-sync/scripts/sync.sh <команда>`
* **Windows (cmd.exe / PowerShell):**
  `%USERPROFILE%\.gemini\config\plugins\antigravity-sync\scripts\sync.cmd <команда>`
* **Универсально (через Python 3):**
  `python3 ~/.gemini/config/plugins/antigravity-sync/scripts/sync_manager.py <команда>`

*(Не требует `rsync` — работает на чистом Python 3 с использованием стандартной библиотеки).*
